# Инструкция по деплою на Render

## Способ 1: Через веб-интерфейс Render

1. Зарегистрируйтесь на [render.com](https://render.com)

2. Нажмите "New +", затем выберите "Web Service"

3. Подключите репозиторий `Deadruke/Bot-Test-Dead`

4. В настройках сервиса:
   - **Name**: bot-test-dead
   - **Region**: Europe (Frankfurt)
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`

5. В разделе "Environment Variables" добавьте:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: ваш токен от BotFather

6. Нажмите "Create Web Service"

7. Дождитесь завершения деплоя (обычно 2-3 минуты)

8. Ваш бот будет доступен по ссылке, которую предоставит Render

## Способ 2: Через render.yaml (автоматический деплой)

1. Подключите репозиторий к Render

2. Render автоматически определит конфигурацию из `render.yaml`

3. Добавьте переменную окружения `TELEGRAM_BOT_TOKEN` в настройках сервиса

4. Деплой начнется автоматически

## Получение токена бота

1. Найдите в Telegram [@BotFather](https://t.me/BotFather)

2. Отправьте команду `/newbot`

3. Следуйте инструкциям для создания бота

4. Скопируйте полученный токен

## Проверка работы бота

После деплоя:

1. Откройте ссылку, которую предоставил Render

2. В Telegram найдите своего бота и отправьте команду `/start`

3. Бот должен ответить "канд дурак дурак дурак"

## Возможные проблемы

- **Ошибка 403**: Проверьте, что токен бота правильный
- **Бот не отвечает**: Убедитесь, что сервис работает и не перезагружен
- **Долгий деплой**: Подождите 2-3 минуты, Render может занять это время

## Мониторинг

На странице сервиса Render вы можете:
- Проверить статус деплоя
- Получить логи работы бота
- Перезапустить сервис при необходимости
